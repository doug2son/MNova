## Verdict

**Test first.** This is the safest version of the press release idea from this source.

Why: Using only the business name and the plain web address as link text is the right instinct, because that's what natural links mostly look like. A first release that simply announces the business is a reasonable thing to do. But the promise that these links will "give you authority" is still unproven. Most press release links are marked so they pass little or no ranking value, and Google's rules treat paid links meant to boost rankings as a link scheme, whatever the link text says. The plan to "mix in keywords" in later releases is still a trash (see [the second release note](2026-11-second-release-and-tiers.md)).

## In a nutshell

- Make the first press release about the brand.
- A release can have up to 5 links (this depends on the provider).
- Point most of them, about 3, at the home page using the business name as the link text.
- The source says the first release should be all branded: the business name or the plain web address, pointing at the home page and the Google Business Profile.
- After that, the source says to start mixing in keywords you want to rank for.
- Expect 2 to 4 weeks, maybe 6, for Google to find and crawl the links.

## What's worth keeping

- **Branded link text only.** The business name or the plain web address (like `examplebusiness.com`) is the safest kind of link text. It's what most real links to a business look like.
- **Point to the home page and the profile.** That's a natural place for a brand announcement to link.
- **Be patient.** It does take a few weeks for Google to find and crawl new pages, so judging results too early is a mistake.
- **A real announcement.** A first release that introduces the business, its owner, its story, and its location is a fair use of a press release.

## Things to watch out for

- **The source contradicts itself a little.** It says "3 of 5 links" branded, then says the first release should be "all branded." Go with all branded.
- **"Authority" isn't guaranteed.** Even with safe link text, press release links usually count for little. Being found and crawled isn't the same as being trusted.
- **Don't plan the keyword links.** Treating this as step one of a plan that ends in keyword link text is the risky part. Keep every release branded.
- **"In my own testing" isn't shared proof.** Ask to see the before and after numbers.
