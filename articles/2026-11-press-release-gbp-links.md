## Verdict

**Test first**

Why: The steps themselves are correct and safe. Nothing here breaks Google's rules. What isn't proven is the idea that these links in press releases help the profile rank higher. Google hasn't confirmed that, and links in press releases usually count for very little. The map embed on my own website is worth keeping because it helps customers, whether or not it helps ranking.

## In a nutshell

There are three ways to link to a profile, and the idea is to put all three in every press release:

1. **The embedded map.** In Google Maps, open the profile, click **Share**, then **Embed a map**, then **Copy HTML**. Paste that code into the press release, and put the same map on the website.
2. **The CID link.** Every profile has a long ID number called a CID. A link built from it looks like `https://www.google.com/maps?cid=1234567890123456789`.
3. **The Maps place link.** This is the full web address from Google Maps. It should start with `google.com/maps/place/` followed by the business name.

## Key takeaways

- Each of the three links points to the same profile in a slightly different way.
- Use the full place link from the address bar, not a search results page.
- The embed code is the same one you can use on your own website.

## What checks out

- **The embed steps are correct.** Share, Embed a map, Copy HTML is exactly how it works.
- **The place link format is correct.** A real place link starts with `google.com/maps/place/Business+Name/` followed by a lot of extra location detail. That's normal. If the address says `google.com/maps/search/` instead, you're on a search page, not the profile.
- **The CID link works.** The `?cid=` link takes you straight to the profile, and it keeps working even if the business name changes.

## Things to watch out for

- **Many press release services strip out embed code.** A lot of the sites that repost releases remove iframes (the type of code a map embed uses), so the map may never show up. Check what the service allows before paying for it.
- **The ranking boost isn't proven.** Most press release sites mark their links as "nofollow," which tells Google not to pass much value through them. Google has also said that links in widely spread press releases shouldn't be used to try to boost rankings. The theory that links to a Maps listing help it rank is popular, but I haven't seen solid proof.
- **Don't overdo the wording around the links.** Stuffing keywords into the link text, like "best plumber in Dallas," is the kind of thing Google treats as spammy.
- **The source doesn't say how to find the CID.** See the steps below.

## How to find the CID number

A few ways, from easiest to hardest:

- Use a free "Google CID finder" tool online. You type in the business and it gives you the number.
- Search for the business on Google, right click the page, choose **View page source**, and search for `ludocid`. The long number after it is the CID.
- Some local SEO tools (like BrightLocal or Local Falcon) show it in their reports.

Then put the number on the end of `https://www.google.com/maps?cid=` and open the link to make sure it goes to the right profile.
