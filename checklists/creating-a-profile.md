# Creating a Google Business Profile

A starting list to work through when setting up a new profile. I'll keep adding to it as I read more.

## Before I start

- [ ] Search Google Maps to make sure the business doesn't already have a profile (claim it instead of making a duplicate)
- [ ] Decide on the exact business name, written the way it appears on signs and paperwork
- [ ] Decide if this is a storefront, a service area business, or both
- [ ] Have the address, phone number, and website ready, and make sure they match everywhere else online

## The basics

- [ ] Pick the primary category carefully, since it matters most
- [ ] Add any secondary categories that truly fit
- [ ] Set regular hours and any special or holiday hours
- [ ] Set the service area if the business goes to customers
- [ ] Write the business description

## Verification

- [ ] Complete verification (video, postcard, phone, or whatever Google offers)
- [ ] Note the date it was verified

## Fill it out completely

- [ ] Add services and/or products
- [ ] Add attributes that apply
- [ ] Upload a logo and cover photo
- [ ] Upload real photos of the place, the team, and the work
- [ ] Add booking or appointment links if they apply
- [ ] Write a first post

## After it's live

- [ ] Ask a few happy customers for reviews
- [ ] Link to the profile from the website
- [ ] Embed the Google map on the contact or location page (Maps, Share, Embed a map, Copy HTML)
- [ ] Find and save the profile's CID number and full Maps place link
- [ ] Add it to the maintenance routine below
